# Lionels Apps

Startseite für Lionels Web-Apps. Für GitHub Pages aus dem Branch `main`, Dateien im Hauptordner.

- [Lese-Abenteuer](lesen/) — Lesen lernen mit Münzen und Shop
- [Mathe-Abenteuer](mathe/)
- [Lese-Test / Mikrofon](lesetest/)
- [Mega-Robo gegen die Riesen-Monster](mega-robo/) — Action-Spiel, im Querformat spielen; als Home-Bildschirm-App läuft es im Vollbild

Der Lese-Test läuft in Safari über HTTPS und fragt nach dem Mikrofon. Auf dem iPad die Diktierfunktion einschalten und die Seite in einem normalen Safari-Tab öffnen, nicht als Home-Bildschirm-App.

`.nojekyll` sorgt dafür, dass GitHub Pages die Dateien unverändert ausliefert.
